About Me

Automating cloud infrastructure, end to end

I'm a DevOps engineer with hands-on project experience automating CI/CD pipelines, containerized deployments, and AWS cloud infrastructure. My work centers on making software delivery faster and more reliable — from provisioning infrastructure with Terraform to shipping builds through Jenkins pipelines.

I've built and managed AWS environments spanning EC2, VPC, IAM, and S3, including designing VPC architecture with subnets, NAT gateways, and secure routing. On the deployment side, I work with Docker and Kubernetes for containerized, microservices-based applications, and Ansible for configuration management.

I'm comfortable troubleshooting across Red Hat and Ubuntu systems, writing shell and Python scripts to automate repetitive tasks, and using Git/GitHub for version control across a team.
